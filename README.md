# Project Directory Structure

## /frontend code
This is the root directory for all frontend code in the project.

### /common
- **/scripts**: Contains shared JavaScript files used across the application.
- **/styles**: Contains shared CSS files for common styling across all modules.

### /login
- **/scripts**: JavaScript files specific to the login functionality.
- **/styles**: CSS files specific to the login page styling.

### /patient-module
This directory contains all features and functionalities specific to patients.

- **/dashboard**
  - **/scripts**: JavaScript files for the patient dashboard.
  - **/styles**: CSS files for styling the patient dashboard.
- **/eating-habit**
  - **/scripts**: JavaScript files for tracking eating habits.
  - **/styles**: CSS files for styling the eating habit tracker.
- **/journal-entry**
  - **/scripts**: JavaScript files for managing journal entries.
  - **/styles**: CSS files for styling the journal entry page.
- **/sleep-tracking**
  - **/scripts**: JavaScript files for tracking sleep.
  - **/styles**: CSS files for styling the sleep tracking feature.

### /therapist-module
This directory contains all features and functionalities specific to therapists.

- **/dashboard**
  - **/scripts**: JavaScript files for the therapist dashboard.
  - **/styles**: CSS files for styling the therapist dashboard.
- **/patient-management**
  - **/scripts**: JavaScript files for managing patient lists and data.
  - **/styles**: CSS files for styling patient management pages.
